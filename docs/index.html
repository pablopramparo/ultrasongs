Antes de empezar

  • Windows 10/11 de 64 bits para el instalador.
  • GPU NVIDIA recomendada. También funciona con CPU, con un procesamiento más lento.
  • Varios GB libres para Python y los modelos de IA.
  • Internet para la instalación inicial. El procesamiento se realiza localmente.
Ver instalación y rendimiento

Proyecto en desarrollo activo. El resultado automático puede necesitar ajustes.
